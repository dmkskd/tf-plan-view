Visualise a Terraform plan

          
Draws the AWS infrastructure a Terraform plan describes. Select a
             resource for its changes, Terraform block and CLI commands.

          
AWS only. Other providers are not supported.


          

            

              1
              

                Turn your plan into JSON. plan.out is a binary
                archive, so it has to be converted first.
                
terraform plan -out=plan.out
terraform show -json plan.out > plan.json

              

            

            

              2
              

                Open it here. Drop plan.json anywhere on this page,
                or use Load plan.json in the top bar. Read in your browser, never
                uploaded.
