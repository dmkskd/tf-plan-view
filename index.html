Visualise a Terraform plan

Reads plan.json and draws it as an AWS architecture diagram. Select any resource to see what the plan changes, its Terraform block, and CLI commands to inspect it.

1
Turn your plan into JSON. plan.out is a binary archive, so it has to be converted first. 
terraform plan -out=plan.out
terraform show -json plan.out > plan.json
2
Open it here. Drop plan.json anywhere on this page, or use Load plan.json in the top bar. The file is read in your browser and never uploaded.

Or click Sample plan to see it with an example.

Reads terraform show -json plan output. Containment is inferred from configuration.root_module.resources[].expressions[*].references. Unrecognised and unplaced resources are listed under Validation.
